# 1u

一个响应式的像素风和好游戏首页，支持电脑与手机。

## 当前内容

- 温馨的薰衣草色夜间卧室主页
- 两个角色的轻微移动与每三秒一次的规律眨眼
- 星星闪烁和心跳式开始按钮
- 全局静音、BGM 音量与音效音量控制
- 手机和桌面自适应布局

## 素材

- `assets/updated-sprites.png`：更新后的五组完整人物图
- `assets/girl-casual.png`：首页女生透明角色素材
- `assets/girl-casual-blink.png`：首页女生闭眼动画帧
- `assets/boy-casual.png`：首页男生透明角色素材
- `assets/boy-casual-blink.png`：首页男生闭眼动画帧
- `assets/bedroom-night.png`：首页夜间卧室背景
- `assets/audio/sfx/`：已接入的 CC0 界面音效（按钮、hover、开关、消息、确认）
- `assets/audio/bgm/`：首页和剧情 BGM 文件位置

## 音频

- 按钮、hover、开关与确认音效来自 Kenney UI Audio，CC0 1.0；许可文件保存在 `assets/audio/sfx/LICENSE.txt`。
- 新消息 ding 使用 Universfield 的 `Soft Bell Ding`，来源为 Pixabay Content License：<https://pixabay.com/sound-effects/technology-soft-bell-ding-485895/>。
- 首页 BGM 已确定为 ChenYueLong 的 `Evening Glow - piano version`。
- 完整 BGM 需要合法取得的音频文件，放入 `assets/audio/bgm/evening-glow.mp3` 后再接入播放器；Spotify 链接不能当作稳定的公开网页音频文件。

直接打开 `index.html`，或通过任意静态服务器预览。
