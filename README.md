# 1u

一个响应式的像素风和好游戏首页，支持电脑与手机。

## 当前内容

- 温馨的薰衣草色夜间卧室主页
- 两个角色的轻微移动与每三秒一次的规律眨眼
- 星星闪烁和心跳式开始按钮
- 全局静音、BGM 音量与音效音量控制
- 手机和桌面自适应布局
